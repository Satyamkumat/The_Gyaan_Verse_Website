PUBLISH USING GITHUB + VERCEL:
1. Download and extract this ZIP.
2. Sign in at https://github.com/ and create a repository named gyan-verse-website.
3. Open the repository, choose Add file → Upload files, upload index.html and README.txt, then commit the changes.
4. Sign in at https://vercel.com/ with GitHub.
5. Choose Add New → Project, import gyan-verse-website, keep the default settings for a plain static HTML site, and click Deploy.
6. Open the generated .vercel.app URL and test all navigation/social links on your phone.
7. To use your own domain, first buy a domain after checking exact availability and renewal price. “thegyanverse.com” is only a suggested name; availability has not been verified.
8. In Vercel, open the project → Settings → Domains → Add Domain. Enter the domain you purchased. Copy the DNS records Vercel displays into your domain registrar's DNS settings. Do not guess DNS values; use the exact records shown in Vercel.
9. Wait until Vercel reports the domain as configured and HTTPS is active. Test both the root domain and www version if you configure both.

UPDATING LATER:
- Edit index.html directly on GitHub or upload the updated file. Each commit to the connected production branch triggers a new deployment.
- To add Facebook, replace the Facebook placeholder <div class="social" ...> with an anchor linking to your actual Facebook Page.
